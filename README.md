# HBL Life — 台灣籃球人生模擬器

從 HBL 高中三年開始的台灣籃球生涯模擬。單一 HTML 檔、手機優先、無任何外部依賴，支援種子碼（相同種子＋相同選擇＝相同人生）。

## 玩法

開場選位置群 → 高一入學選學校（名門／中堅／新興）→ HBL 三年養成 → 畢業路口（UBA 一級／二級・台灣職籃選秀・赴 CBA・赴美）→ 三軌職業生涯 → 兵役 → 衰退 → 引退結算與名人堂票選。

一局約 300～350 次點擊，從 16 歲打到 35~38 歲。

## 數據與獎項

數據採 NBA 官方欄位（`GP / MIN / PTS / FGM / FGA / FG% / 3PM / 3PA / 3P% / FTM / FTA / FT% / REB / AST / STL / BLK / +/−`），分成**例行賽・季後賽・分區冠軍賽・總冠軍賽**四段累積。模擬基準來自 `NBA.xlsx` 的分級平均數據表（S～F 級 × 五個位置），能力值只在基準上做修正。

獎項含月最佳球員／新秀、MVP（米高·佐敦獎）、最佳防守球員（Hakeem Olajuwon 獎）、最佳新人（Wilt Chamberlain 獎）、最佳第六人（John Havlicek 獎）、進步最多球員（George Mikan 獎）、最佳關鍵球員（Jerry West 獎）、東西區第一～三隊、防守第一～三隊、五大單項王＋三分王、分區冠軍 MVP、總冠軍 MVP、明星賽 MVP。**拿獎會給能力點**，所以獎項本身就是養成的一部分。

特殊賽事有季後賽三輪、明星賽、季中錦標賽（NBA 盃）、新秀對抗賽、技術挑戰賽、三分球大賽、灌籃大賽——後幾項的入選要看能力門檻（例如灌籃大賽要彈跳 > 50）。

## 位置樹

```
後衛 ─┬─ 控球後衛 ──→ 雙能衛（兼具得分與控球）
      └─ 得分後衛
前鋒 ─┬─ 小前鋒 ────→ 全能鋒線（兼具大小前鋒）
      └─ 大前鋒
中鋒 ─── 中鋒（不分化・門檻最低・最容易養成）
```

- **分化**（進職業後）採比較式：`控球＋視野 ≥ 三分＋切入` → 控球後衛，否則得分後衛；前鋒比 `三分＋單防` vs `籃板＋彈跳`。
- **進化**要三～四項能力同時達標，且必須先站上控球後衛／小前鋒。雙能衛與全能鋒線的薪資係數最高（×1.16／×1.14），出賽分鐘 +2。
- **中鋒**只看籃板／彈跳／單防，門檻最低；代價是薪資係數最低（×1.00）且被洋將壓縮最重（×0.70）。
- 內線位置吃身高：大前鋒／中鋒／全能鋒線的門檻隨身高調整，長不高就站不住。

## 三個核心機制

| 機制 | 說明 |
|------|------|
| **抽高** | 成年身高出生時依位置群暗抽（後衛 181±5／前鋒 194±5／中鋒 204±5 公分），16 歲時還沒長完，高中三年每年隨機長 1–5 公分。身高是唯一不能用點數練的能力，卻決定你在群內站得住哪個位置。19–20 歲有 5% 機率二次發育；長太高或沒長高時可跨群轉型一次。 |
| **洋將壓縮** | 台灣職籃每隊 3 名洋將，位置越靠內線上場時間壓縮越重（中鋒 ×0.70、後衛 ×1.00）。在 CBA 你自己就是亞洲外援，不壓縮，但連兩年打不出來直接解約。 |
| **曝光度** | HBL 有轉播與短影音。名門給你冠軍與曝光但球權被學長壓縮；新興學校給你全隊球權卻沒人看見。曝光度決定 UBA 招募、選秀順位與代言收入。 |

## 舞台階梯

- **學生／台灣**：HBL 乙級 → HBL 甲級 → UBA 二級 → UBA 一級 →（社會甲組）→ 台灣職籃培訓 → 台灣職籃一隊
- **CBA**：CBA 青年隊 → CBA 一隊（註冊滿 5 年轉國內球員身分，門檻 −4）
- **美國**：預校／JUCO → NCAA D2 → NCAA D1 → G League → NBA

跨軌入口只有五個：選秀、赴美（ovr≥44）、赴 CBA（ovr≥42）、NBA 夏季聯盟邀請、下放遞約。

## 種子碼

網址加上 `?seed=xxxx` 可重現同一段開局：

```
https://<你的帳號>.github.io/hbl-life/?seed=hbltest1
```

同一顆種子的「球員誕生」（能力、潛力、成年身高）完全固定；之後每個選擇都會推進共用的 RNG 序列，所以同種子＋不同選擇會長出不同人生。

## 本機預覽

```bash
node hbl-life/server.js
```

開 <http://localhost:8123>。或直接雙擊 `index.html`（純靜態，不需要伺服器）。

## 部署（GitHub Pages）

推上 GitHub 後在 **Settings → Pages → Source** 選 `main` 分支的根目錄即可，網址為 `https://<帳號>.github.io/<repo>/`。

## 名稱使用原則

- 高中（HBL）與大學（UBA）採真實校名，且僅作正面描寫；「新興學校」一律使用虛構校名，不把弱旅標籤貼到真實學校上。
- 職業球隊（台灣／CBA／NBA）全部使用避免版名稱，保留辨識度但不綁定真實商標。
